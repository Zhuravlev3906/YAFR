Yet Another File Manager - файловые менеджер (по факту всего лишь организатор с возможностями файлового менеджера) для сортировки файлов на основе их расширений, автопереименовывания файлов (например 1.ext, 2.ext или S01E01.ext, S01E02.ext и так далее)

Архитектура:
- CLI слой. Занимается обработкой CLI
- Enigine. Движок. Занимается переименованием файлов и обработки ошибок
- Config. Занимается загрузкой конфигурации
- App. Точка входа. Объединяет в себе все слои и запускает приложение
